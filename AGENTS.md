# Agent notes

This repository is a Next.js 16 App Router template. Prefer Server Components, TanStack Query for client state, and `lib/env.ts` for validated public environment variables.

When changing routes, metadata, env vars, or scripts, update `README.md` and `.env.example` together.

Cursor rules live under `.cursor/rules/` and describe SEO, analytics, performance, and project conventions.

- Pull requests must follow `.cursor/rules/pr-format.mdc` and `.github/pull_request_template.md` (including pr-gate follow-up before you report the PR done).
